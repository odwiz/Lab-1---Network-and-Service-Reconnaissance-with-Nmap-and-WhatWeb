# Lab-1---Network-and-Service-Reconnaissance-with-Nmap-and-WhatWeb
## Scenario
## Practical context
You are acting as a junior security analyst assigned to perform authorised reconnaissance against an intentionally vulnerable system within the ICDFA isolated training environment. Before any deeper security testing can take place, you must identify the target, determine which network services are exposed, identify service versions, examine the likely operating system, and fingerprint any exposed web service. Your findings will form the initial reconnaissance record for subsequent web application testing.

## Lab Objectives
This laboratory showcases how I was able to identify hosts within an authorised network, perform common Nmap reconnaissance scans, interpret open ports and service information, perform service and operating-system detection, use Nmap NSE discovery scripts, conduct TCP and UDP reconnaissance, fingerprint a web service using WhatWeb, and document findings professionally.

## Tools and Resources Used
The tools and resources used during this lab are:
o	Kali LinuxLinux operating system (Kali Linux)
o	Metasploitable 2
o	nmap
o	whatweb
o	Curl
o	Terminal access


## Conclusion 
At the end of the lab I was able to differentiate between host discovery, port scanning, service/version detection, operating-system detection, aggressive scanning, full-port scanning, UDP reconnaissance, NSE enumeration and web fingerprinting.
